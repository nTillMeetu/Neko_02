## v8（当前）

### 1. 月份按钮的箭头重叠

- 原因：`.uo-pill` 的基础内边距规则写在 `.uo-picker-trigger` 之后，把右侧 26px 的
  留白覆盖掉了，箭头于是压在「月」字上。
- 修法：把触发器写成 `.uo-pill.uo-picker-trigger`（更高优先级），右侧留白与颜色都拿回来；
  API 键的触发器同理（`.uo-pill.uo-select-trigger`）。

### 2. API Key 下拉的白色空白

- 原生 `<select>` 的弹出菜单由系统绘制，在这套深色界面里会是一块白底、还带一段空行。
- 改成自绘列表：触发器是同一个胶囊（`API Key 全部 API Key ⌄`），点开是深色浮层，
  选项为按钮（当前项填充品牌色），点外部或 Esc 关闭；键盘可用。
  空白、白底、主题不一致三个问题一起消失。

### 3. 每月消耗 → 和每日消耗一样的月份格子

- 去掉「表格 + 收起/展开」，改成 **月份网格**：一行 6 格（手机 3 格），
  每格是一个月：左上「2026年9月」、左下 Tokens、右下金额；底色按「该月花费 ÷ 最贵月份」
  分四档热力，当前月用墨色细环绕一圈。
- 点任意一个月份格子 = 把上面的每日日历切到那个月（和月份选择器等价，少点一步）。
- 月份从账号首月补到当前月，中间没有数据的月份显示 `¥0.00`；月份多了会自然换行，
  不再需要折叠按钮。

### 实机验证（这一轮 Host 不用重启）

- 月份选择器：在真实界面里从 2026年11月 切到 2026年10月、再通过月份格子切到 9月，
  日报表数据、统计条、热力都跟着变（Host 的 `?month=` 已经在上一轮重启后生效）。
- 当天浮层：点 10/20 弹出「2026年10月20日 · 消费金额 ¥0.00 · Tokens 0 · API 请求 0」，
  点外部 / Esc 关闭。
- API Key：自绘下拉在真实界面里正常展开、选中、收起。
- `inspect.mjs --app`：深色 / 浅色均 `0 FAIL`；`lint.mjs`：`0 FAIL`。

### 仍然存在的小问题

- 月份较少时（比如现在 3 个），6 列网格右侧会留空，随月份累积会逐渐填满。
- 月份选择器的可选范围是「账号首月 → 本月」，更早的月份置灰。
- 11 月刚过零点，当月数据只有 1 天，默认打开当前月时会显得空——这是真实数据。
